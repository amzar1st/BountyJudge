# What an approval means

An approval says that independently fetched public code and diff evidence supports every immutable requirement under the configured AI review. It is scoped to the submitted PR head SHA, repository, requirements digest, and wallet binding.

It does not establish runtime correctness, security, personal authorship, repository ownership, successful deployment, or professional accreditation. Requirements needing those facts must remain UNKNOWN unless independently verifiable evidence within the supported scope supplies them.

Failed core evidence retrieval leaves the review unresolved. Invalid optional challenge/response attachments are recorded individually without vetoing reliable code evidence. Available counter-evidence remains part of the assessment and cannot be deleted or replaced by the parties.

A reward transfer request is permitted only after application-level finalization of an approved decision. GenLayer transaction finality and successful execution must also be checked; transaction finality alone is insufficient. Recipient credit must be observed separately from message emission.
